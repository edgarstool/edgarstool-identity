# v0.1 Acceptance Checklist

驗收標準：**Edgar 能在 30 秒內看懂目前整個 EDGAR-OS 地景，而且不需要任何後端服務。**

## A. 30 秒理解測試（核心）

- [ ] 開啟 `/` 後，5 秒內能看到 Current focus（當前焦點）與其 guardrails。
- [ ] 一屏內同時看得到：active systems、project status summary、Now 項目、Inbox 數量。
- [ ] 全站顯著位置出現：「Control Center is the planning source of truth. Chats propose changes; the map changes only after review.」

## B. Architecture（架構圖）

- [ ] `/architecture` 顯示所有節點：Local Windows Host、Cloudflare、MCP Gateway、Hermes、OpenClaw、Agent-KB、Obsidian、Automation、Auth、GitHub。
- [ ] Cloud / VPS 以虛線標示為 optional infrastructure。
- [ ] 節點之間有連線且標註關係名稱。
- [ ] 點擊任一節點會開啟 detail drawer，內含 role、owns、does not own、location、connections、risks。
- [ ] hover 節點時，非相鄰節點淡出。
- [ ] 從 Dashboard 或 Command Palette 點入可直接選中對應節點。

## C. Projects（專案登錄）

- [ ] 八張卡片皆存在：Hermes、EDGAR Auth、MCP Gateway、Agent-KB、BIG、Control Center、AI Gateway Observability、Cloudflare Feature Sprint。
- [ ] 每張卡片顯示 status、purpose、dependencies、canonical repo/path、next action、maturity（Formal / Experiment / Deprecated / Unknown）。
- [ ] repo 未知時以警示圖示與 Unknown 樣式呈現，不被隱藏。
- [ ] 可依 status 篩選。

## D. Roadmap（路線圖）

- [ ] 四個 lane：Now / Next / Later / Inbox。
- [ ] 可新增項目（標題、細節、lane、status）。
- [ ] 可直接就地編輯標題與細節。
- [ ] 可左右移動 lane、可刪除。
- [ ] 重新整理頁面後資料仍在（localStorage）。
- [ ] 可一鍵還原成 seeded data。

## E. Inbox（收件匣）

- [ ] 可捕捉新想法。
- [ ] Promote to Project 會在 Roadmap 建立對應項目，並標記來源項目為 Promoted。
- [ ] Archive / Restore 可切換，封存項目可獨立檢視。
- [ ] 重新整理後資料仍在。

## F. Command Palette（指令面板）

- [ ] `⌘K` / `Ctrl+K` 開啟。
- [ ] 可搜尋 projects、systems、workflows、tools、roadmap items。
- [ ] 選取後導向正確頁面（並在架構圖中選中節點）。

## G. Design & Quality（設計與品質）

- [ ] 深色、沉穩的 command-center 風格，無 sci-fi 雜訊。
- [ ] Desktop-first，且在手機寬度可用（側欄可收合）。
- [ ] Status chips 六種狀態顏色一致：Active、Planning、Paused、Experimental、Deprecated、Unknown。
- [ ] 所有資料處皆標示 "Seeded / manually maintained data — no live health checks in v0.1."
- [ ] `npm run build` 成功，無 TypeScript 錯誤。
- [ ] 每個路由都有專屬的 title 與 description。

## H. 明確排除（Out of scope）

- [ ] 沒有 auth、Supabase、OAuth、live API、部署基礎設施。
