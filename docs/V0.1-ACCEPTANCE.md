# Identity Service Acceptance Contract

> Status: Active documentation contract for `edgarstool/edgars-tools-identity`.

本文件取代舊的 EDGAR-OS Control Center v0.1 驗收清單。Control Center 內容已不再是本 repository 的正式產品範圍。

## A. 產品定位

- [ ] 首頁、README、metadata、Privacy、Terms 與部署說明都把本服務描述為 EDGAR'S Tools Identity and Authorization Service。
- [ ] 不再把 `auth.edgars.tools` 描述為 EDGAR-OS 控制中心、Project dashboard、Roadmap 或 Inbox。
- [ ] 尚未拆出的 Control Center 程式碼與文件被清楚標示為 legacy／pending split，不被誤認為 production contract。

## B. 正式網域與分支

- [ ] 正式網域是 `https://auth.edgars.tools`。
- [ ] repository 預設與正式部署分支是 `master`。
- [ ] workflow、文件與 handoff 不再引用 `main` 作為正式分支。
- [ ] GitHub Actions 部署的 Cloudflare target 與 `auth.edgars.tools` 實際綁定的 Worker 相同。

## C. 核心路由

以下 route 必須存在或明確回報尚未實作，不得用文件假裝已完成：

- [ ] `/`
- [ ] `/login`
- [ ] `/register`
- [ ] `/authorize`
- [ ] `/callback`
- [ ] `/forgot-password`
- [ ] `/reset-password`
- [ ] `/logout`
- [ ] `/auth/success`
- [ ] `/auth/failed`
- [ ] `/access-denied`
- [ ] `/session-expired`
- [ ] `/privacy`
- [ ] `/terms`

## D. 身分與授權

- [ ] Supabase Auth 設定指向正確專案。
- [ ] 登入、登出與 session 恢復完成實際驗證。
- [ ] OAuth 2.1 authorization flow（授權流程）完成實際驗證。
- [ ] OpenID Connect issuer、redirect URI 與 callback 一致。
- [ ] 預設 owner 帳號包含 `edgar@edgars.tools` 與 `edgar@edgar.tw`。
- [ ] `edgar@edgarbeyourself.com` 不再被新增為預設允許帳號。

## E. Secrets 與環境設定

- [ ] Cloudflare API token、service role key、OAuth client secret、JWT signing secret 等敏感值未出現在 repository、frontend bundle 或 log。
- [ ] `VITE_*` 僅包含可公開給瀏覽器的設定。
- [ ] 缺少必要 environment variable 時，workflow 在部署前清楚失敗。
- [ ] workflow 不輸出 secret value。
- [ ] GitHub Secrets／Variables 與 Cloudflare Worker secrets 的責任邊界有文件記錄。

## F. Build 與部署

- [ ] dependency install 成功。
- [ ] lint 成功。
- [ ] typecheck 成功。
- [ ] production build 成功。
- [ ] GitHub Actions 成功。
- [ ] Cloudflare deployment 成功。
- [ ] 線上 HTML、title 與目前部署 commit 相符。
- [ ] 主要路由完成 public smoke test。

## G. 內容品質

- [ ] 每個主要頁面有符合用途的 title 與 description。
- [ ] Privacy／Terms 不宣稱未實作的資料保護或稽核能力。
- [ ] 中英文產品名稱與用途一致。
- [ ] 文件清楚區分 Fact（事實）、Current Status（現況）、Planned（規劃）與 Unknown（未知）。

## H. Git 收尾

- [ ] 修改在隔離 branch 完成。
- [ ] commit 與 PR 說明變更目的、驗證結果與未完成項目。
- [ ] 沒有覆蓋不屬於本任務的變更。
- [ ] 未完成的 Control Center 拆分被明確記錄，不宣稱已完成。

## 完成判定

只有文件、程式碼、CI、Cloudflare 線上部署與實際登入／授權驗證全部一致，才可宣稱本服務已完成部署。單純 workflow 綠燈不等於產品正確。
